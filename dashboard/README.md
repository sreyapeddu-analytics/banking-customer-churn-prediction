# Dashboard

This project ships the charts a churn-monitoring dashboard would show, pre-rendered
in [`images/`](../images/). The same visuals are generated by
[`src/model.py`](../src/model.py) and the executed notebook
[`notebooks/analysis.ipynb`](../notebooks/analysis.ipynb).

| Chart | What it shows |
|---|---|
| `churn_by_segment.png` | Churn rate by tenure band and by products held |
| `roc_curves.png` | ROC curves for both models (test set) |
| `confusion_matrix.png` | Confusion matrix — Random Forest @ 0.5 threshold (test set) |
| `feature_importance.png` | Top 10 Random Forest feature importances |

## KPI definitions

| KPI | Definition | Current value (synthetic data) |
|---|---|---|
| **Churn rate** | `SUM(churned) / COUNT(*)` over the customer base | **16.21%** |
| **Retention rate** | `1 − churn rate` | **83.79%** |
| **At-risk segment size** | Inactive members with tenure ≤ 24 months and exactly 1 product — customers where a retention campaign has the most leverage | **430 customers (4.3% of base)**, churning at **46.7%** |
| **Model ROC-AUC** | Area under the ROC curve on the held-out test set (25%, stratified) | **0.726** (Logistic Regression), **0.712** (Random Forest) |
| **Campaign recall** | Share of actual churners the model would flag (Random Forest @ 0.4 threshold) | **78.8%** recall at 23.7% precision |

### Suggested dashboard layout

1. **Overview row:** churn rate, retention rate, at-risk segment size, model ROC-AUC
2. **Drivers row:** churn by tenure band, churn by products held
3. **Model row:** ROC curves, confusion matrix, feature importance

In a BI tool (Tableau / Power BI), these KPIs map to calculated fields over the
`customers` table; the segment queries in [`sql/analysis_queries.sql`](../sql/analysis_queries.sql)
are the underlying data source.
