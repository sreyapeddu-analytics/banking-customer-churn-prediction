# Data

## `customers.csv` — synthetic banking customer dataset

**10,000 rows · ~0.5 MB · fully synthetic — no real customer or employer data.**

Generated by [`src/generate_data.py`](../src/generate_data.py) with `numpy` (`random_state=42`).
Churn is engineered so that low activity, short tenure, and fewer products drive a
higher churn probability; the overall churn rate is **16.21%**.

### Schema

| Column             | Type   | Description                                      |
|--------------------|--------|--------------------------------------------------|
| `customer_id`      | int    | Unique synthetic customer ID (100000–109999)     |
| `age`              | int    | Customer age (18–79)                             |
| `tenure_months`    | int    | Months as a customer (0–120)                     |
| `balance`          | float  | Account balance in USD                           |
| `num_products`     | int    | Number of bank products held (1–4)               |
| `has_credit_card`  | int    | 1 = holds a credit card, 0 = does not            |
| `is_active_member` | int    | 1 = active member, 0 = inactive                  |
| `estimated_salary` | float  | Estimated annual salary in USD                   |
| `geography`        | string | USA / UK / Canada                                |
| `gender`           | string | Male / Female                                    |
| `churned`          | int    | **Target:** 1 = churned, 0 = retained            |

### Regenerate

```bash
python src/generate_data.py
```
